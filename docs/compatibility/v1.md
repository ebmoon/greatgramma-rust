# v1 compatibility profile

No grammar, regex, tokenizer, or Python generation profile is supported yet.
This bootstrap reserves a fail-closed compatibility boundary:

- the eventual core consumes owned normalized token bytes, a priority-resolved
  byte DFA, and conflict-free LALR tables;
- ordinary token byte entries will be nonempty and EOS IDs will represent one
  semantic EOS event;
- unsupported tokenizer decoders, nullable terminals, unresolved priorities or
  conflicts, error recovery, and context-sensitive indentation will be
  rejected rather than approximated;
- Python Torch and Transformers integrations are not dependencies or supported
  interfaces in this revision.

The Aeneas smoke profile is frozen independently: Aeneas
`5d08da45a405913bbee6fd544e01debf8154ac9d`, Charon
`f5208b1c4ce287898a1fc015d41a20da3baf0974`, Rust
`nightly-2026-06-01`, and Lean 4.31.0.
