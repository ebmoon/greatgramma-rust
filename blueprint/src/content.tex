\section{Authority and roadmap}

This document describes the intended proof dependency graph for the
GreatGramma Rust semantic kernel.  It deliberately separates implementation
refinement from conditional language correctness.  The graph and its colors
are navigational aids only.  The authoritative evidence is Lean elaboration,
the generated-declaration and public-API inventories, the proof manifest, and
the root-theorem axiom audit.

The roadmap has four documentation states.  \emph{Planned} nodes are orange
and have no Lean link.  \emph{Linked} nodes point to one stable handwritten
Lean declaration but make no completion claim.  \emph{Proved} nodes have
passed the authoritative gates before receiving their completion marker.
\emph{Assumption} nodes remain conditional forever, even if their proposition
is represented in Lean.  No state in this document is proof evidence.

\section{Generated core to finite-head refinement}

\begin{definition}[U1: reproducible generated boundary]
  \label{def:generated-proof-boundary}
  \bpstatus{planned}
  \notready
  Split Aeneas output, translation metadata, exact dependency pins, and the
  generated inventory define the reproducible boundary between Rust and the
  handwritten proof.  Aeneas owns the files listed in the generated manifest;
  the two excluded, declaration-free external bridge modules import reviewed
  models from \texttt{proofs/External/}.  The smoke gate reconciles those
  bridges with the Rust template hooks and elaborates the generated root.  The
  pinned extraction still uses
  \texttt{partial\_fixpoint} for all 46 translated loops, so totality remains
  an explicit U2 feasibility obligation.  Blueprint output is outside both the
  generated and Lean dependency graphs.
\end{definition}

  buffer on failure.

\section{Conditional language correctness}

\begin{proposition}[U9: realizability adapter]
  \label{prop:realizability-adapter}
  \bpstatus{planned}
  \notready
  \uses{asm:token-bytes-correct, asm:lexer-dfa-correct, asm:lalr-language-correct}
  The frozen UCSD-style byte-coverage, pruning, and universal-separator
  hypotheses give a sufficient adapter for the direct continuation-realizability
  premise.  The root theorem accepts the direct premise and does not require
  this stronger corollary.
\end{proposition}

\begin{theorem}[U9 / Root 2: pure language theorem]
  \label{thm:finite-head-language-correct}

\begin{theorem}[U9 / Root 3: composed core-language theorem]
  \label{thm:core-language-correct}

  \textbf{CoreLanguageCorrect.}
  The generated Rust core implements grammar-constrained decoding for reachable
  normalized histories by composing the implementation and pure-language
  roots, while retaining both roots' assumptions visibly.
\end{theorem}

\begin{theorem}[U9: intended-grammar corollary]
  \label{thm:intended-grammar-corollary}
  \bpstatus{planned}

  the core's accepted language equals the intended grammar language and its
